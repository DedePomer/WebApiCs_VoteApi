# Программа (API) для глосования 

API для организации голосования: вы логинитесь, получаете список кандидатов и отправляете свой голос за выбранного кандидата.


##  Возможности

- Аунтификация с помощью двух JWT (access и refresh);
- Пересоздание refresh токена при обращении;
- Получение кандидатов;
- Голосование за определённого кандидата;


## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/DedePomer/WebApiCs_VoteApi.git
cd REPO_NAME
```
### 2. Запустить docker-compose (порт по у молчанию 8080)
```bash
docker compose up
```

## Используемые технологии

- Языки: C#;
- Фреймворки: ASP.NET, Entity Fraemwork;
